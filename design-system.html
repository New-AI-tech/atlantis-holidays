A luxury-aligned system, documented

Every color, type size, spacing value, and component below is the exact CSS this site's tools are built from — nothing here is illustrative-only. Change a token in assets/css/tokens.css and every page that imports it updates.

Color

Purple remains the brand's primary — it's what the actual logo uses. Gold marks premium/featured content; teal is a new secondary accent tied to the "Atlantis" ocean motif, used as the "Viewed" status color in the Proposal Manager.

Typography

Fraunces, self-hosted, six weights. One typeface throughout — hierarchy comes from weight and size, not a second typeface.

display / 600Private Desert Safari
xl / 600Proposal Manager
lg / 600Hotel Confirmation Voucher
md / 300 italicInteractive Proposal & Quotation Generator
base / 400Body copy sits here — confirmation numbers, guest names, line items.
sm / 500Field Label
xs / 400Helper text and timestamps

Spacing

4px base scale — every margin, padding, and gap in this system is one of these eight values.
