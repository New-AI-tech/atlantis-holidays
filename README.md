# atlantis-holidays

Client-side Word proposal generator for Atlantis Holidays & Wellness.

## Features

- Runs 100% in the web browser using JavaScript (`docxtemplater`, `pizzip`, `FileSaver.js`).
- No Python backend server required.
- Dynamically parses line items, quantities, unit rates, and totals.
- Generates polished `.docx` proposals directly from `template.docx`.
- Hosted on GitHub Pages.
